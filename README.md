# cortico-world-checkin

> 控制台里显示为 **Where Are You**（扩展 `id` 和包名仍是 `checkin` / `cortico-world-checkin`，配置键、工具名前缀都不变）。

Coopanion 的桌宠默认只在你说话的时候回应。Where Are You 补上另一半：让它知道什么时候可以不等你开口——
但它不替你说话，只把由头递到模型手上。

Cortico World 扩展（契约 `api: 6`），给 Coopanion / 任何带 World 的 Cortico 宿主用。

## 它做的四件事

**一、跟进（主）**

你提到一件以后会想知道结果的事（「三点约了人」「明天要早起赶车」），Coo 用 `checkin_note` 记下来。
到点扩展推一条 `checkin.due`，正文是第一人称的提醒 + 当前时间。说不说、怎么说，仍然由 Coo 自己决定。

**二、搭话（副，可关）**

扩展隔一段时间看一眼**前台是哪个程序 + 窗口标题 + 多久没动键鼠**。给由头的路有两条：
一个是你在同一个窗口前连着待了很久（`sameAppMinutes`），一个是到点了它主动看一眼你在做什么（`lookEveryMinutes`，默认 30 分钟一次，可以关）。
两种情况都推 `checkin.activity`，给 Coo 一个「可以搭一句」的由头。你连着戳两下桌宠、或者离开一阵子又回来，也算由头。

**三、走太久递个由头（可关）**

离开一阵子还没回来，它会递一条 `checkin.away`：正文写清他走了多久、离开前在做什么，以及判断口径——
先翻对话和课程表，有答案就别问；真没线索、又想问，怎么问、去哪个会话问，由模型自己在工具列表里找。
Where Are You 不存 QQ 号，也不碰别的 World 的工具。安静时段不递，一趟离开只递一次。

**四、摸两下，陪你看十分钟（可关）**

连着摸桌宠两下以上（不是戳，是顺着毛摸的那种），接下来一阵子它每隔一会儿看一眼你的前台窗口（默认 10 分钟、每 2 分钟一眼，共五眼；时长和间隔都能在设置里改）。
第一眼可以开口打个招呼，后面只是陪着，不催它说话；到点自己停，不用你再管。只摸一下不算。

它**不读屏幕内容、不联网**，样本只在内存里留最近约四小时；只有真要开口时才截一张整个屏幕的图（可以关）。

## 它不做什么

- 不自己发消息。所有对外的话都由模型调 `pet_say` 说出来——扩展没有能力越过模型替你安排台词。
- 不提醒「喝水」「久坐」。只接得住具体的事，不制造空口寒暄。
- 不在安静时段出声。到点的跟进会等你出了安静时段再提。

## 装

```bash
# 在 Coopanion 的扩展目录里
pnpm add cortico-world-checkin
```

然后在部署的 `config.json` 里启用：

```json
{
  "worlds": {
    "checkin": { "enabled": true }
  }
}
```

重启 Coo 生效（World 是启动时挂载的）。

## 配置

设置页按语义分成四块，每块一个小标题、一段说明，各存各的（改一块不会牵连另一块）。
带单位的几项，单位写在输入框后面，标题里就不再带「（分钟）」了。
「提醒过的跟进多久清掉」不在这里——它只影响「待跟进」那一栏，就放在那一栏里改。

**搭话** —— 看窗口的频率、要不要顺手截图、什么时候递由头（待够了，或者到点看一眼）。

| 键 | 默认 | 说什么 |
| --- | --- | --- |
| `watchActivity` | `true` | **监测**：看不看前台窗口。关掉就只做跟进，完全不碰窗口信息（状态页那一行就是它） |
| `screenshot` | `true` | **截图**：真要开口时截一张**整个屏幕**的图（JPEG、约 1280 宽、不落盘；多显示器时是所有屏幕的并集）；当前模型看不了图就自动跳过 |
| `sampleSeconds` | `60` | **间隔**：前台窗口多久看一次（15–3600 秒，改了立刻生效） |
| `sameAppMinutes` | `90` | **持续**：同一个程序要连着待满多久才递一个由头（5–480 分钟） |
| `lookEveryMinutes` | `30` | **看一眼屏幕**：另一条给由头的路——不管换没换窗口，每隔这么久主动看一眼你在做什么（0–720 分钟，`0` = 关掉，只按上面的「持续」给） |

**怎么样才算「看到前台」** —— 采样器每一轮只问 Windows 三件事：最前面那个窗口属于哪个程序、标题是什么、键鼠最后一次动是多久前。「看到前台」= 那一刻有窗口、而且不是 Coo 自己。它看不见：窗口里在干什么（只有标题一行字）；键鼠是不是真的在动——`idleMs` 是全局最后一次输入的时间，手柄、脚本、远程桌面都算「用过」，反过来看视频、读书时人明明在，它也会显示「键鼠停了 20 分钟」；切换走了又切回来（两次采样之间的来回等于没发生）；应用内部的停留（浏览器里换标签页，前台程序一直是一个）。

**手停着，人还在不在？** 这条 `idleMs` 回答不了——看书、看画、看片时手就是不动。所以键鼠停着超过 3 分钟时，它另外截一张 **32×18 的灰度指纹**（`src\print.ps1`，约 288 ms、1.3 KB、不落盘），和上一张比：画面在变就说明人在消费内容（人在、专注、屏幕上正好是那幅画那页书），照样递由头，正文会写「他 N 分钟没动键鼠了，但画面一直在变」，`meta.focused === true`；画面停住超过 10 分钟，才当人真的不在。指纹每秒最多取一次，且只在键鼠停着时才取；取不到画面（没权限、锁屏）就当「不知道」，仍按离开判定走。

所以判断分三档，从宽到严：**有窗口、程序不是自己** → 可能在看；**`idleMs` 超过 3 分钟** → 再看画面在不在变，停住超过 10 分钟才不给由头；**`idleMs` 超过离开判定**（默认 15 分钟，看片放宽一倍）→ 人走了，走离开/回来那一套。当初先做成「键鼠停 5 分钟就不给」是错的：那正好把「他在看一幅画」当成「他不在」，而截图里其实有足够内容让它说一句贴题的话。


**桌宠上的动作** —— 摸它、戳它之后会发生什么。

| 键 | 默认 | 说什么 |
| --- | --- | --- |
| `pokeNudge` | `true` | 连着戳两下桌宠就去看一眼，顺便决定要不要说句话（单戳不算） |
| `companion` | `true` | 连摸两下以上就陪着一阵（下面两个数决定多久、多密） |
| `companionMinutes` | `10` | 这一段陪多久（1–60 分钟） |
| `companionEveryMinutes` | `2` | 陪的时候隔多久递一眼（1–30 分钟；填得比总时长还长就只递一眼） |

**离开与回来** —— 人走开了它怎么看、回来时说一句。

| 键 | 默认 | 说什么 |
| --- | --- | --- |
| `backNudge` | `true` | 离开过一阵子又回来时，可以说一句「回来啦」（半小时最多一次，安静时段不说） |
| `awayMinutes` | `15` | 键鼠停这么久算「人不在」（1–240 分钟，看片时按两倍算） |

**限制** —— 两条之间隔多久、一小时和一天最多几条、哪段时间闭嘴。

| 键 | 默认 | 说什么 |
| --- | --- | --- |
| `softGapMinutes` | `90` | 两条搭话之间至少隔多久（0–480 分钟，`0` = 不设间隔，但被无视时的退避仍按 **5 分钟**起算）；被无视会自动翻倍（最多八倍） |
| `softPerHour` | `2` | 一小时内最多几条，`0` = 不限 |
| `softPerDay` | `3` | 一天最多几条（`0` = 不限） |
| `quietFrom` / `quietTo` | `00:30` / `04:30` | 安静时段，本地时间 `HH:MM`，可以跨午夜 |

**待跟进面板里的一项**（不在设置页）：

| 键 | 默认 | 说什么 |
| --- | --- | --- |
| `staleMinutes` | `60` | 提醒过一次、之后一直没结果的跟进，过这么久就自动从列表清掉（5–1440 分钟）；从没提醒到的保留三天 |

上面除 `quietFrom`/`quietTo` 的语义外都是热更新的，改完下一次评估（最多 15 分钟）就按新值走，不用重启。
四个门槛是「与」的关系：连续时长（或那一眼的间隔）达标、当天额度没满、这一小时没超、距上次超过间隔，才会递一个由头。
同一个程序没有「一天只递一次」的限制——只有 `softGapMinutes` 那条时间间隔管着；间隔填 `0` 时，被无视的退避仍从 **5 分钟**的基数起算
（无视一次翻一倍，最多八倍=40 分钟），免得一关间隔就变成刷屏。

判定「人不在」看的是 `awayMinutes`（默认 **15 分钟**；看片时按两倍算——按前台程序是不是播放器、
或浏览器标题里有没有视频站来判断）。人不在的时候不搭话；等你回来、并且 `backNudge` 开着，才推一条「回来啦」的由头
（安静时段不说，半小时内最多一次）。采样拿到的 `idleMs` 是采样那一刻的，判定时会把「采样到现在又过去的时间」补上。

## 工具

| 工具 | 用途 |
| --- | --- |
| `checkin_note` | 记一条以后要问的事（`text` + 可选 `afterMinutes`，默认 120） |
| `checkin_list` | 看还挂着哪些、什么时候提 |
| `checkin_done` | 有结果了，标掉这一条 |
| `checkin_activity` | 现在前台是什么、多久没动、最近一小时换过哪些程序 |

跟进记录落在 `<部署数据目录>/worlds/checkin/threads.json`，纯本地。

提醒过一次、之后一直没结果的跟进会自己清掉（`staleMinutes`，默认一小时；记为 `dropped`，不是完成），
这样列表里不会一直挂着已经过去的事。从来没轮到提醒的（比如一直跨在安静时段）保留三天。

## 事件

| 事件 | 什么时候 |
| --- | --- |
| `checkin.due` | 一条跟进到点了（不在安静时段） |
| `checkin.activity` | 同一个程序前连续待满 `sameAppMinutes`（默认 90 分钟），或者到了 `lookEveryMinutes` 那一眼（默认 30 分钟），且额度、间隔都允许，人也没走；键鼠停着时要画面还在变才会递（`meta.focused` 为真）；或者他连着戳了两下桌宠；或者他离开一阵子又回来了 |
| `checkin.away` | 离开超过 `awayMinutes` 还没回来（一趟离开只递一次，安静时段不递）；递过之后一直没落账会再补一条只让记账的（也只补一次，`meta.verdict === 'reminder'`） |
| `checkin.companion` | 连摸两下以上之后，这一段里按 `companionEveryMinutes` 递一眼前台（第一眼带 `speak`，后面不带；眼数由时长和间隔算） |

`checkin.due`、连续搭话和「回来啦」都用 `trigger: 'flush'` 立刻叫醒模型；
连戳两下那条用 `'debounce'`，好跟桌宠自己那条 `desktop-pet.touch` 并进同一批。`checkin.away` 不带 `speak`：
它不要求你说话，只把「要不要问一句、去哪儿问」递过去（扩展自己发不了 QQ，也不存目标，发消息得模型自己找工具）。
真要开口时（`screenshot` 开着、当前模型能看图）会顺手带一张整个屏幕的截图。

## 连戳两下桌宠

桌宠被戳时会推到事件库里一条 `desktop-pet.touch`，但**它是合并过的**：桌宠把 2.5 秒内的同种触碰合成一条事件，
真戳了几下写在 `meta.touch.count` 里——连戳两下就是一条事件、`count: 2`。所以 Where Are You 数的是 `count`，
不是事件条数；`count: 1` 的单戳不算。Where Are You 每秒扫一次事件库的尾部队列（游标只在内存里），凑够两下就立刻
采一次样、推一条 `checkin.activity`——没有点 callback 可用，框架的 `WorldHost` 不提供跨 World 的回调，只能读
`host.store`。扔、摔不算（摸是另一条路，见下节）；说了一句之后 20 秒内的戳不再开口；走同一条搭话通道，所以照样会截图。戳完那一秒
前台往往是 Coo 自己（鼠标还在桌宠身上），这时不采样、直接用最近一条真实样本兜底（30 分钟内），文案里写清
「这一眼是戳之前的样子」。

## 连摸两下，陪着看十分钟

同一个触碰通道里，「摸」（`pet`）和「戳」（`poke`）是分开数的：摸的那条事件 `meta.touch.kind === 'pet'`，
`count` 同样是被合并过的。两下之间不超过 3.5 秒、攒够 2 下就开一段陪伴；已经陪着的时候再摸不会把时钟往后拖。
之后按 `companionEveryMinutes`（默认 2 分钟）递一眼全屏截图（`shot.ps1`，只在内存里、不落盘），
`companionMinutes` 到了就停（默认 10 分钟，一共五眼；间隔填得不小于总时长时就只看一眼）；
面板「连摸两下桌宠」关掉、或者 `worlds.checkin.companion: false` 就完全不轮询。陪伴不看安静时段——
是他自己摸出来的。第一眼带 `speak`（可以先打个招呼），后面不带，纯看着，免得十分钟里催它说五句话。

## 离开 / 回来

采样顺带就能看出人走没走：`idleMs`（全系统最后一次键鼠输入到现在）超过 `awayMinutes` 就算离开，
这时候不搭话、不算活跃时长；等你碰了键鼠、下一次采样看到 `idleMs` 落回阈值以下，就认为你回来了，推一条
`checkin.activity`（`meta.back === true`，正文写「离开了一会儿又回来了（大约 N 分钟）」）。离开不到一个阈值（比如起身倒杯水）
不算；单戳一下也不算；安静时段不说；半小时内最多一次。连戳两下或手动搭话也会重置这个半小时的冷却。

### 走久了递个由头

离开超过 `awayMinutes`（默认 15 分钟）还没回来，Where Are You 会推一条 `checkin.away`，正文写清他走了多久、
离开前的前台是什么，以及判断口径。**它不存 QQ 号、也不调 `qq_send`**：要不要问、问给哪个会话，是模型看自己的
工具列表决定的（QQ 那边的 World 装了什么发送工具，它就能用什么）。一趟离开只递一次，回来就复位；安静时段不递。

「离开」在扩展这边只意味着**人不在电脑前**，不代表他在不在别处；他去干什么，扩展不知道、也不猜——
正文把顺序写清楚，让看得见对话和课表的模型自己走：

1. 先找线索：翻对话（他走之前说过「我出去一趟」），再看工具列表里有没有课程表、日程表这类安排（装了才查得到）。
2. **分清「知道」和「猜」**：知道只有两种——他走前交代过、日程里查得到；按「这个点该吃饭了」「这么晚一般睡了」推出来的都算猜。知道就按知道的来，不问；上课时间人不在是**正常的**，不说「人呢」「翘课了」，回来再说「下课啦」。
3. 只有猜、或者什么都不知道：回来问一句「刚才去哪儿啦」就够，不用非得发到手机；要现在问，才在工具列表里找能把话送到手机上的东西（QQ 那边的发送工具、别的通知渠道都算），有的话优先发给他本人，别往群里发，一两句话、不追问。**别替他编答案**（「饭吃过了嘛」这种）。
4. 这趟都得落账：用 `checkin_note` 写一条。问过了记「等他回」，**先别 `checkin_done`**，等他真答了再结；知道事实的记「日程：…」；只是猜的就记「猜的：估计去吃饭了，还没问，回来问一句」——猜的不算结论，这条留在待跟进里。这一条是 0.1.13 改的：原来写的是「有答案就按答案来，不用问」，模型于是把猜测当答案，人没被问、待跟进里也空的。

递出去之后过了 **20 分钟**（固定在代码里，不跟 `awayMinutes` 联动、也不进设置页）还没落账，它会再推一条 `checkin.away`（`meta.verdict === 'reminder'`、不带 `speak`）：
正文明确「不要开口、也不要给 TA 发消息，只把结论写进 `checkin_note`」。**一趟只补一次**，补过就不再提；人回来了立刻复位。
之所以是「一次只记账的补账」而不是连环催：框架里没有强制模型调用工具的手段，能做的只有把要求写死在措辞里，
再给一次只许记账的机会；真连这条也不理，只在日志里留一句 `checkin: 这趟离开没落账`。

他在 QQ 上回你，**不算回到设备前**——那反而说明人还在外面。Where Are You 自己不碰课程表、不碰 QQ（跨 World 硬耦合，装了才用），
只负责递这个由头；用哪个工具、说不说，都在模型那边。
## 控制台面板

- **状态**：最上面三行是**监测**、**采样间隔**、**看一眼屏幕**（它看不看窗口、多久看一次、另一条由头的间隔），接着是搭话时截图、连戳两下桌宠、连摸两下桌宠三个开关，再往下是今天说了几条、**画面在不在变**（键鼠停着时它凭什么判断你还在看）、离开/回来的判定；最底下是眼下采到的前台程序、窗口标题、键鼠空闲、连续时长和最近一小时。只读，不带任何按钮。
- **待跟进**：`checkin_note` 记下的事按到点顺序列出来，可以当场「结掉」（等价于 `checkin_done`），不用等它到点。这页底下还能改「提醒过的跟进多久清掉」（`staleMinutes`）——**改完自动存**（输入停顿一下、回车或点走都会存，没有按钮），直接写进 `config.json`，不用重启。

## 为什么要这么绕

第一版我们把事件写成第三人称日志（「检测到前台窗口变化」），模型永远 `end_turn`——那不是对它说的话。
现在事件正文是第一人称、带具体时刻、末尾明确给一个「要不要说」的余地：**由头在扩展，决定在模型，出口在 `pet_say`**。

## 平台

- Windows：跟进 + 前台窗口都支持（Win32 `GetForegroundWindow` / `GetLastInputInfo`）。
  截图也是 Win32 + `System.Drawing`，只在真要开口时截一张，不写文件。
- 其他平台：跟进照常；前台窗口采样和截图自动跳过。
